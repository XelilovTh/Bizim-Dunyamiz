# 🌸 Bizim Dünyamız (Fidan & Təhmaz)

Xüsusi sevgimiz və xatirələrimiz üçün sıfırdan hazırlanmış müasir React SPA layihəsi.

---

## ✨ Xüsusiyyətlər
- 🌌 **Giriş Ekranı:** Şifrə qoruması, IP təhlükəsizliyi və Telegram bildiriş sistemi.
- 📸 **Xatirələr (Foto Albom):** Cloudinary CDN ilə avtomatik sıxılma (WebP/AVIF), dinamik kateqoriyalar və tam ekran baxış rejimi.
- 💌 **Sevgi Məktubları:** Xüsusi zərf açılma animasiyası, oxunmamış bildirişlər və yeni məktub yazma imkanı.
- 🎵 **Musiqi Pleyeri:** Fırlanan qrammofon valı (Vinyl), dinamik pleylist, kilid ekranı pleyer idarəetməsi (`MediaSession`).
- 🤖 **Telegram İnteqrasiyası:** Ziyarətçi məlumatları (ISP, Cihaz, Şəhər) üçün bildiriş botu və Telegram vasitəsilə birbaşa foto/musiqi/məktub yükləmə botu.
- ⚡ **Yüksək Performans:** SWR keşləmə (0ms yüklənmə), Code Splitting (React.lazy), PWA dəstəyi.

---

## 🛠️ Texnologiyalar
- **Frontend:** React 19, Vite, React Router 7, Lucide Icons, CSS Variables & Glassmorphism
- **Storage & Media:** Cloudinary (Şəkillər və Audio)
- **Database & Versioning:** GitHub API
- **Serverless API & Hosting:** Vercel
- **Bot:** Telegram Bot API (Webhook & Polling)

---

## 🚀 Quraşdırma & İşə Salma

```bash
# Asılılıqları yükləyin
npm install

# İnkişaf mühitini başladın
```
